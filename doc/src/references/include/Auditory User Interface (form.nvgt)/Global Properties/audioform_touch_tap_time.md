# audioform_touch_tap_time
Set the timing of taps on a touch screen in forms, in milliseconds.

`uint audioform_touch_tap_time = 500;`

## Remarks:
This is both the longest that a finger can stay on the screen and still count as a tap, and the longest gap allowed between the 2 taps of a double tap.

Raise this for players who need more time to double tap.
