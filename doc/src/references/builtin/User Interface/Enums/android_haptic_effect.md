# android_haptic_effect
These are the short, crisp vibrations that an Android phone provides itself, for use with android_vibrate_effect.

* ANDROID_HAPTIC_CLICK: A single click, good for confirming an action.
* ANDROID_HAPTIC_DOUBLE_CLICK: Two clicks in a row.
* ANDROID_HAPTIC_TICK: A very light tick, good for moving through a menu or list.
* ANDROID_HAPTIC_HEAVY_CLICK: A stronger click, good for something important such as taking damage.
